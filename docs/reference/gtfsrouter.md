# gtfsrouter

Routing engine for GTFS (General Transit Feed Specification) data,
including one-to-one and one-to-many routing routines.

## Main Functions

- [`gtfs_route()`](https://UrbanAnalyst.github.io/gtfsrouter/reference/gtfs_route.md):
  Route between given start and end stations using a nominated GTFS data
  set.

- [`go_home()`](https://UrbanAnalyst.github.io/gtfsrouter/reference/go_home.md):
  Automatic routing between work and home stations specified with local
  environmental variables

- [`go_to_work()`](https://UrbanAnalyst.github.io/gtfsrouter/reference/go_to_work.md):
  Automatic routing between work and home stations specified with local
  environmental variables

- [`gtfs_traveltimes()`](https://UrbanAnalyst.github.io/gtfsrouter/reference/gtfs_traveltimes.md):
  One-to-many routing from a nominated start station to all stations
  reachable within a specified travel duration.
